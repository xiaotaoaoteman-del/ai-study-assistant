# AI 学习助手

一个使用 Python 和 DeepSeek API 开发的命令行 AI 问答程序。

## 已实现功能

- 通过命令行向 AI 提问
- 支持连续提问
- 输入 `quit` 退出程序
- 自动拦截空问题
- 处理 API 请求异常
- 从系统环境变量中读取 API Key

## 使用技术

- Python
- DeepSeek API
- OpenAI Python SDK
- Git
- GitHub
